# Discord capability audit — alpha.4

Audited 2026-10-02 against the official sources below, before implementation. FULL SUPPORT means support for the documented, metadata-only signal, not access to every aspect of the Discord feature. Permission coverage and collection start time remain visible. No Message Content, Presence or DM intent is requested.

| Feature | API / Gateway support | Intent | Bot permission | Community requirement | Observability | Privacy | NEXUS use | Implementation status | Fallback |
|---|---|---|---|---|---|---|---|---|---|
| Guild / channel structure | Get Guild, Get Guild Channels; guild/channel events | Guilds | ViewChannel for activity | No | Counts and accessible structure; private thread total unknown | Minimal IDs/types, no names used for meaning | Capability discovery | FULL SUPPORT | UNKNOWN on read failure; explicit blind spots |
| Members / roles | member add/update/remove; Get Guild Member | GuildMembers (privileged) | None for events | No | Delivered member metadata, not all member history | Scoped HMAC identity; roles and dates only | Journey, staff exclusions | FULL SUPPORT | Missing intent flagged; no fake backfill |
| Rules Screening | Guild feature; member.pending | GuildMembers | None | Community for setup | Pending and observed transition; not rules acceptance text | Boolean and timestamps | Start engagement clock when pending clears | FULL SUPPORT | Unknown pending does not prove screening completed |
| Native Onboarding | Get Guild Onboarding; member flags | Guilds, GuildMembers | Read endpoint; capability errors preserved | Community for configuration | Enabled/mode/default IDs, prompt/option counts and assignments; started/completed flags | No selected answers or prompt text | Avoid duplicate onboarding; journey context | FULL SUPPORT | Unavailable / permission missing / unknown distinct |
| Server Guide / Home actions | Member STARTED_HOME_ACTIONS / COMPLETED_HOME_ACTIONS | GuildMembers | None | Community | Flags observable; complete guide configuration has no documented public read endpoint | Flags/times only | Journey context, never engagement gate | CONTEXT ONLY | Enabled state UNKNOWN until flags observed |
| Legacy Welcome Screen | Get Guild Welcome Screen | Guilds | ManageGuild if disabled | Community | Configuration retrievable; endpoint has no enabled field | Count/IDs only | Legacy context | CONTEXT ONLY | Successful read does not prove enabled |
| Guest members | IS_GUEST member flag; voice member joined_at can be null | GuildMembers, GuildVoiceStates | ViewChannel | Feature dependent | Observed guests; not durable ordinary membership | Hash, voice segment only | Separate guest counts; no retention cohort | FULL SUPPORT | Unknown flag stays unknown |
| Text / announcements | MESSAGE_CREATE type and reference | GuildMessages | ViewChannel | Announcements generally Community | Message metadata only; unreadable channels excluded | No body/attachments/embed | Direct replies and purpose-aware activity | FULL SUPPORT | Partial coverage shown |
| Voice / Stage text chat | MESSAGE_CREATE on type 2 / 13 channel | GuildMessages | ViewChannel | Stage feature dependent | Text is separate from voice attendance | Same metadata whitelist | VOICE_TEXT / STAGE_TEXT surfaces | FULL SUPPORT | Unknown channel type remains UNKNOWN |
| Public / private / announcement threads | THREAD_CREATE/UPDATE/DELETE/LIST_SYNC/MEMBERS_UPDATE; List Active Guild Threads | Guilds; GuildMembers for other members' thread updates | ViewChannel; private membership or ManageThreads | Parent dependent | Accessible active threads; archived history not enumerated; member_count capped at 50 | IDs, owner hash, metadata, not title/body | First-class surface, restore mapping on restart | FULL SUPPORT | Private/archived blind spot disclosed |
| Forum posts / tags | Type 15 parent; thread metadata and applied_tags | Guilds, GuildMessages | ViewChannel | Availability dependent; inspect actual structure | Post creation, first other-human response, mapped tags | No post title/body; explicit admin tag mapping | Support/LFG/feedback workflow | FULL SUPPORT | Archive / lock never means resolved |
| Media posts | Type 16 parent, thread events | Guilds, GuildMessages | ViewChannel | Feature dependent | Post metadata and replies; not media content | No attachments or analysis | Showcase context | FULL SUPPORT | Unknown / absent KPI omitted |
| Direct replies | message_reference.message_id | GuildMessages | ViewChannel | No | Observed reference to retained metadata | IDs and response latency | Strong human connection | FULL SUPPORT | Unretained reference unknown; no message REST lookup |
| Mentions | MESSAGE_CREATE mentions user metadata | GuildMessages | ViewChannel | No | Delivered explicit human mentions only | Hash targets; no mention content | Context only, not reply proof | CONTEXT ONLY | Empty metadata means unknown, not no mentions |
| Reactions | ADD with optional message_author_id; REMOVE, REMOVE_ALL, REMOVE_EMOJI | GuildMessageReactions | ViewChannel | No | Active edges since deployment, unique human participants; no history backfill | HMAC emoji key; no emoji semantics | Weak response; never first connection | FULL SUPPORT | Unknown author leaves received metric unassigned |
| Polls | MESSAGE_POLL_VOTE_ADD/REMOVE; poll field omitted without Message Content | GuildMessagePolls | ViewChannel | No | One active participant per user/poll, irrespective of selected answer count | HMAC answer key; no question/options/opinions | Medium participation only | FULL SUPPORT | No creation/content/history metrics |
| Voice co-presence | VOICE_STATE_UPDATE; channel AFK ID | GuildVoiceStates | ViewChannel | No | Continuous observed human co-presence, threshold default 5 min | No audio/transcript; no pair graph | Context-aware connection proxy, never conversation proof | FULL SUPPORT | Gaps/restarts interrupt duration evidence |
| Stage | Voice suppress flag; stage instance lifecycle | GuildVoiceStates, Guilds | ViewChannel | Stage feature dependent | Speaker vs audience segments; listening not conversation | No recording/topic | Stage participation, event attendance | FULL SUPPORT | Unknown suppress kept unknown |
| Scheduled events | create/update/delete + user add/remove | GuildScheduledEvents | ViewChannel for associated channel | Entity dependent | Subscription distinct from observed Voice/Stage attendance during known ACTIVE window | Event ID/type/status; no description | Event funnel | FULL SUPPORT | External attendance unknown; scheduled time not attendance proof |
| AutoMod | List rules; rule change events; ACTION_EXECUTION | AutoModerationExecution; configuration if requesting rule events | ManageGuild for list rules | No blanket requirement | Rule count/hash and action type/user/channel/time | Drop content, matched content, keywords and rule names | Safety context; never member bad score | CONTEXT ONLY | Permission missing; blocked content not a sent message |
| Incidents / safety | guild.incidents_data, guild feature flags | Guilds | Endpoint-dependent | No | Documented incident timestamps only | No inferred raid participants | Caveat for period comparison | CONTEXT ONLY | Absence is not proof of no incident |
| Discovery | DISCOVERABLE guild feature | Guilds | None | Eligibility dependent | Feature flag; no reliable acquisition attribution | Flag only | Server context | CONTEXT ONLY | No discovery conversion metric |
| Announcement following | Follow endpoint returns webhook; message crosspost flags | GuildMessages | ManageWebhooks to follow | Announcement parent | NEXUS cannot reliably know readers / receiving-server retention | No webhook/body collection | No engagement metric | NOT RELIABLY OBSERVABLE | Explain attribution unavailable |
| Soundboard | List soundboard sounds; sound send and update events | GuildVoiceStates / GuildExpressions where applicable | UseSoundboard / ViewChannel | No blanket requirement | API exists, unrelated to durable onboarding connection | Sound assets not collected | Omitted from engagement | DEFERRED | No activity score from sound usage |
| Voice effects | VOICE_CHANNEL_EFFECT_SEND | GuildVoiceStates | Channel access | No | Ephemeral effect event, not human conversation | Not collected | Omitted | DEFERRED | No effect-derived connection |
| Stickers / emoji assets | List/update guild expressions | GuildExpressions | Endpoint dependent | No | Asset inventory, usage content restricted | Assets / semantic labels not collected | Reactions use only hashed emoji keys | DEFERRED | No sticker interest inference |
| Invites / attribution | Invite APIs/events | GuildInvites | ManageChannels / ManageGuild as documented | No | Aggregate counters do not reliably identify individual join source | Invite/user attribution not collected | None in alpha.4 | DEFERRED | No invented source cohort |
| Presence / DM / audio / message content | Privileged or content APIs | Not requested | Not applicable | No | Outside product collection boundary | Never collected | None | DEFERRED | Metadata-only transparency |
