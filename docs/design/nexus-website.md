# Project Nexus product website

The public site describes the implemented **Discord Community Operations** product. The corporate product website redirection directive takes precedence over the earlier concept design. Unimplemented functionality is excluded even when it could be labeled conceptual or planned. Product availability remains alpha; paid checkout is unconfigured and paid prices are unpublished.

Voice co-presence is not proof of conversation. Event signup and observed attendance are distinct. Reaction participation does not imply sentiment or a first connection. Observation limits remain explicit; missing data is not presented as zero. The preview's 28/38 first connections use a completed illustrative 72-hour cohort, not an uncompleted calendar week.

## Design and components

`apps/web/app/page.tsx` is a localized server composition with product metadata and real installation/login routes. `landing/navigation.tsx` provides a small accessible menu. `landing/product-preview.tsx` reproduces shipped dashboard fields with labeled sample data; switching between Overview, Attention and Evidence never operates a real server. Static examples show available actions without fake actionable buttons. Native FAQ disclosures work without JavaScript.

The restrained light site has a 1280px maximum container, 48/32px desktop horizontal padding, 60/56px desktop H1, 42px H2, 26px H3, 16–17px body, and 96px desktop section spacing. Mobile spacing is 64–72px and horizontal padding 20px. The real product preview uses a dark surface with labeled states. There are no numbered chapters, ambient motion, pinned scenes, parallax, scroll hijacking or generated background art. The only numbers outside sample product data are the three small setup steps.

CSS is scoped to `.nexus-site`; it does not restyle the authenticated dashboard. `public-ui.tsx` reuses the navigation, mark and real product preview; `landing/public-pages.css` applies the same visual language to product, pricing, privacy, support and terms pages. The detailed product page uses normal feature labels without chapter numbers. Geist is self-hosted by Next's font handling. Japanese uses the existing system fallback. The `/nexus/` proxy exclusion serves only public brand assets; protected routes remain protected.

The original mark remains. `public/nexus/social-preview.svg` and `.png` describe the actual Discord product. Obsolete concept components and atmosphere are removed from the current source; the incoming work was preserved in the ignored `.local/nexus-before-corporate-2026-10-04.zip` before replacement.

When changing public copy, confirm implementation and availability first. Reference-company capabilities, registry entries marked planned and roadmap documents are not evidence of an available feature. Available-only pricing is filtered using `featureAvailability`, without changing billing contracts or entitlements.
