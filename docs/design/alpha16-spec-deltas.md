# alpha16 最新ユーザー方針の差分

2026-10-16。添付正本のbyteは変更せず、後続の明示ユーザー指示をこの台帳に記録する。

## 推奨される対応を直接表示する

ユーザー指示：**「承認制はやめてほしい。あくまでも推奨される対応ということを明記」**。

現在の閲覧権限を持つ利用者に提案を直接表示する。表示前の承認ワークフローを作らない。`REVIEW_ONLY` は提案だけで設定変更・Discord投稿等の副作用を起こさない能力境界であり、表示待ちの状態ではない。利用者が推奨内容を読み、自分で対応を判断する。

根拠、情報不足、最終観測、期限、限界を説明する。推奨と記載するだけで運営者の責任がなくなるとの表示はしない。restrictedな根拠は現在の専用権限を維持する。適用時の現在権限・対象・危険操作確認・重複防止・UNKNOWN非再送は変更しない。

Rule/config/source・保持の運用gateは表示前の承認とは別。未取得データを架空の提案へ変換しない。提案履歴を読む権限と、個人の閲覧済み状態を永続化する保持条件も別である。

## 保持期間の選定委任

ユーザーは **「推奨される期間で結構です」** と具体値の選定を委任した。後続の確定表を受領したため、以下を新設データのソース上の契約へ反映する。現行実データへの削除適用・運用設定変更は今回しない。

|新設class|live上限と起点|
|---|---|
|評価Fact・evaluation・source-health snapshot・根拠|作成/封印から最大48時間。元sourceが早ければ優先。読出し・retry・コピーで延長しない|
|最小提案履歴|生成から原則14日。保存ボタンで延命しない。根拠期限後は値・コピー除去、適用不可|
|最小操作監査|操作から原則14日。自由文・secret・payload禁止。既存別目的監査と分離|
|reject/dismissの再表示抑止|選択から原則14日。版変更だけで解除しない|
|削除受付receipt|受付から原則14日。失効でjob/tombstoneを解除しない|

Run終端後7日以内削除とbackup7日は維持。Run詳細を14日枠へ移して延命しない。既存元データ・日次集計・長期比較指標すべてを48時間で消す指示ではない。

TARGET_LIVE_SAFETY、復元防止tombstone、公開撤回世代は独立の安全class。90日案は採用しない。欠落・期限切れでUNKNOWNを解除せず、対象寿命・再照合・復元契約が未成立の外部Applyは無効を維持する。提案表示は独立して実装する。

Rule別minN/freshness/cooldown/閾値は正本候補を維持し、fixtureと実運用profileを分離する。一律値への置換や表示前承認は行わない。稼働profile検証と実運用有効化は別工程。
